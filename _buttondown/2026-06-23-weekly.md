### [MCP: cuándo merece la pena y cuándo gana el CLI (el caso de GitHub)](https://claudecodesessions.com/cuando-usar-mcp/)

Instalas el MCP de GitHub porque parece la forma *correcta* de darle a Claude acceso a GitHub, y una semana después te preguntas si aporta algo que `gh pr list` no haga sin tanta ceremonia. Para GitHub, el CLI suele ganar: una herramienta que el modelo ya domina frente a unas cuarenta y un servidor que mantener vivo. Pero el MCP se gana el sitio donde no hay CLI, no hay shell, o quieres permisos por herramienta — la regla de decisión completa, dentro.
